# 歡樂的耍費時光｜南瓜員工旅遊邀請函

南瓜虛擬科技股份有限公司，2026/11/12–11/13 墾丁夏都兩天一夜互動邀請網站。

公開網站（免登入）：https://terry12260201.github.io/pumpkin-kenting-holiday-2026/

## 體驗

蓄力闖關 → 傳送門轉場 → 海景揭幕 → 公司邀請 → 互動旅程島嶼。
支援觸控、滑鼠、鍵盤、跳過遊戲、重播與減少動態效果。

## 本機預覽

不需要安裝套件或編譯。在此目錄執行：

    python -m http.server 8000

開啟 http://localhost:8000。

## 檔案

- `index.html`：完整邀請與行程資訊。
- `prologue.js`、`prologue.css`：遊戲序幕、揭幕動畫與互動地圖。
- `app.js`、`style.css`：兩日行程、景點、集章與行李清單。
- `assets/`：公司官方角色原始圖及真實景點參考照片。
- `driver.html`：可列印的司機行程草案。
- `invitation.txt`、`holiday.ics`：邀請文案與行事曆。
- `sources.html`：素材來源與核對紀錄。

## 編輯與部署

這是無後端的靜態網站，可部署至支援 HTML/CSS/JavaScript 的主機。
GitHub Pages 從 main 分支根目錄部署；推送至 main 後會自動更新公開網站。
使用者互動進度僅保存在訪客自己的瀏覽器。

## 行程狀態

活動店家、餐廳、集合點、第二天午餐等仍待主辦確認。照片中的店家為實景參考，不代表已預訂。
